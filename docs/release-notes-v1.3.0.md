# JWSK v1.3.0 · 原生 Root 管理器

本次将旧 ADB 管理器重构为 Android 14+ 的独立 Root 管理器。
应用 ID 保持 `cn.jiangwang.jwsk`，使用原 JWSK 发布密钥签名；APK 内不包含私钥。

## 主要变化

- KernelSU v3.3.1 原生超级用户、应用配置、模块、日志及内核设置。
- Magisk Alpha 的授权、策略、模块启停、设置、排除列表与离线 Boot / init_boot 修补。
- 超级用户按应用图标、名称、包名展示；ROOT 标签来自真实授权，UID 放在详情中。
- 原生 Miuix 玻璃界面、furry 主题、深色模式和可关闭的模糊效果。
- 四个页面：主页、超级用户、模块、工具。安装与修补只有一个入口，API 配置统一放在设置。
- AI 文本助手支持 13 类提供商配置；Comput 保持独立手动终端，凭据使用 Android Keystore 加密。
- 接收用户自行编译的 GKI 内核/镜像；App 不编译整核、不自动刷写分区。
- 修复原证书在 KSU 中的识别、v2-only 签名格式、旧版 x86 内核入口兼容和授权标签刷新。

## 验证范围

- 117 项 Android 单元测试、17 项 APK 协议/签名格式检查；Rust 检查和双架构原生构建。
- Android 14 x86_64 模拟器中验证 KSU / Alpha 的原证书识别、实际 Root、独立 UID 授权及撤销。
- KSU 精确匹配模块正常加载与冷启动；模块安装/列表/启停、设置读写和实际内核日志读取。
- Alpha 冷启动、离线 v4 init_boot 修补、原镜像保持不变、策略与模块/设置管理。
- 原生手机、深色、放大字体与扩展屏幕截图复核；截图不等于硬件性能测试。

最终构建、签名及运行记录以随包的 `stable-validation.json` 为准。
发布使用通过验收的同一个签名 APK，不另外生成一个未经安装检查的包。

## 安装前须知

- 最低 Android 14；APK 包含 arm64-v8a 与 x86_64。Android 15/16 的实体机仍需自行确认后端兼容性。
- 安装 APK 本身不会让任意手机获得 Root；KSU 内核/LKM 必须匹配设备并认可 JWSK 身份。
- 本轮没有实体测试手机，不能承诺全厂商、全固件或硬件帧率。低资源模拟器曾出现系统界面无响应；更高资源下完成后续验证，不据此宣称原因已完全排除。
- 没有使用真实凭据逐一调用全部 AI 服务；第三方模块、WebUI 与隐藏模块需要独立兼容性及来源核验。
- Shamiko 等第三方闭源模块不作为内置能力承诺；本版本保留兼容后端的模块管理入口。
- 镜像修补仅生成新文件。请保留原厂镜像与恢复方案，错误刷写可能导致无法启动或数据丢失。

下载后可对照 `SHA256SUMS` 校验 APK。开源来源与许可证见仓库 README 和第三方声明。
